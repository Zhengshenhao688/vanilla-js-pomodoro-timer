# Timer 番茄钟项目

## 项目概述
**Timer** 是一个基于 **纯 JavaScript、HTML 和 CSS** 的可交互番茄工作法计时器。它帮助用户科学管理时间，提高工作和学习效率。该项目功能完整，界面美观，并实现了响应式设计，可在桌面和移动设备上使用。

---

## 功能亮点

1. **自定义时间输入**  
   - 用户可以手动输入分钟和秒数，设置任意 1 秒至 59 分 59 秒的计时。

2. **番茄钟模式**  
   - 一键切换番茄钟模式，自动管理工作时间和休息时间。  
   - 工作与休息阶段自动切换，并带有提示音提醒。

3. **控制按钮**  
   - 播放 / 暂停  
   - 重置  
   - 番茄钟启动 / 退出  

4. **设置弹窗**  
   - 可设置工作时间（1-120 分钟）和休息时间（1-60 分钟）。  
   - 弹窗固定高度 200px，内容整齐排列，UI 友好。  

5. **使用说明弹窗**  
   - 带小圆形关闭按钮，方便用户查看操作说明。

6. **音效与静音功能**  
   - 番茄钟结束自动播放提示音，可随时静音。  

7. **响应式设计**  
   - 可在移动端和桌面端自适应显示，按钮和文字大小自适应屏幕。  

---

## 技术栈

- **前端技术**：HTML5, CSS3, JavaScript (ES6+)  
- **音频**：HTML Audio API  
- **图标**：Google Material Icons  
- **响应式设计**：媒体查询（Media Query）

---

## 使用说明

1. **打开页面**：在浏览器中打开 `index.html`。  
2. **输入时间**：可直接输入分钟和秒数，或点击番茄按钮启动番茄钟模式。  
3. **控制计时**：  
   - 点击播放 / 暂停按钮控制计时器  
   - 点击重置按钮重置计时器  
   - 点击静音按钮切换提示音  
4. **查看设置**：点击番茄按钮弹出设置窗口，设置工作和休息时间。  
5. **查看使用说明**：点击左下角 “i” 按钮，弹出使用说明。
